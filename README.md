# AI-Interview-Preparation-Assistant
AI-powered interview preparation assistant using Python, NLP, LLM and FastAPI.
## Overview

An AI-powered application designed to help users prepare for
technical interviews through role-specific questions,
answer evaluation and personalized feedback.

## Features

- Role-specific interview questions
- Technical question generation
- Answer evaluation
- Performance scoring
- Personalized feedback
- Improvement suggestions

## Technologies

- Python
- NLP
- LLM
- FastAPI
- REST API
